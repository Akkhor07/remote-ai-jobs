# Remote AI Jobs

Hand-picked, fully remote AI jobs open to people worldwide. A one-page site for the Remote AI Jobs LinkedIn page.

**Live site:** https://akkhor07.github.io/remote-ai-jobs/

## Adding jobs

Edit the `JOBS` list near the bottom of `index.html`. Each job takes a title, company, category, pay, tags, posting date and an apply link (micro1 jobs can use `M1("post-id")` to add the referral code automatically).
